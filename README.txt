# QR Festa — Control d'accés

## Què fa
- La persona obre la pàgina amb el QR.
- Durant 1,7 segons veu una pantalla seriosa de "CONTROL D'ACCÉS".
- Després apareix "BENVINGUT A LA FESTA".
- Hi ha un efecte visual i un botó per activar un so de benvinguda.
- No guarda noms, dades ni registres.
- El mateix QR pot servir per a tothom.

## Posar-ho online gratis
La manera més senzilla és publicar `index.html` amb GitHub Pages.
Un cop tinguis l'adreça pública, genera un QR que apunti a aquesta adreça.

IMPORTANT:
El fitxer és una pàgina web completa i no necessita servidor ni base de dades.
El so és generat pel navegador, així que no depèn d'un fitxer de música extern.

Si vols una cançó concreta, pots substituir l'efecte per un fitxer d'àudio propi,
però els mòbils poden bloquejar la reproducció automàtica; per això el botó
"ACTIVAR SO DE BENVINGUDA" és la solució fiable.
